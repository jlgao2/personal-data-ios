# Personal Data — iOS Companion

Single-screen SwiftUI app that mirrors the [`personal-genome-pipeline`](https://github.com/jlgao2/personal-genome-pipeline)
desktop dashboard's **Action Loop** on iPhone, with **live HealthKit reads**
overriding the cached values from the laptop bundle.

## Status

- ✅ Builds (`Debug` for `iphonesimulator`, Xcode 26.3)
- ✅ Renders Action Loop, Stack, Pre-flight Check, Today header from sample bundle
- ⚠ HealthKit reads work on real device only (simulator has no Health data)
- ⚠ iCloud Drive sync not yet exercised end-to-end

## Build

```bash
xcodegen generate                 # if you've changed project.yml
open PersonalData.xcodeproj
# or from CLI:
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild \
  -project PersonalData.xcodeproj \
  -scheme PersonalData \
  -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  CODE_SIGNING_ALLOWED=NO build
```

## Architecture

```
┌──────────────────┐  iCloud Drive   ┌────────────────┐
│  laptop pipeline │ ──ios_bundle───▶│  iOS app       │
│  refresh.sh      │                 │  HKHealthStore │
└──────────────────┘ ◀─samples_*────┘  live reads     │
                                     └────────────────┘
```

- Laptop publishes `output/ios_export/ios_bundle.json` on each `refresh.sh`
  (covered by sibling repo's `publish_ios_export()`)
- iOS reads the bundle, overlays HealthKit live values per `sample_type`
- iOS writes `samples_YYYY-MM-DD.json` back daily — laptop ingests on next refresh

```
└── Resources/
    ├── Info.plist               Generated by xcodegen
    ├── PersonalData.entitlements
    └── sample_bundle.json       (gitignored — 450KB sample, generated from data-vitals.js)
```
